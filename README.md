# BrewCraft Coffee — WordPress Landing Page

A single-page WordPress website built for the fictional brand **BrewCraft Coffee**, created as part of the Full Stack Development Intern hiring assignment for Plan-a / ClickToScale.

> **Status:** Part 1 (Development) is complete. Part 2 (Technical SEO) is not yet started.


## What Was Built

A one-page WordPress landing site with the following sections:

- **Hero** — full-bleed background image, headline, subtext, and a CTA button linking to the Products section
- **About** — brand story section with image and copy
- **Products** — 3 product cards (Signature Espresso, Cold Brew, Signature Latte) with images, descriptions, and pricing
- **Contact** — contact form built with Contact Form 7

The site was custom-coded (hand-written HTML/CSS/JS embedded within WordPress) rather than relying on a page builder or a theme's default layout, for full control over design and structure.

The layout is fully responsive and has been checked across mobile and desktop breakpoints.

## Tech Stack

- **WordPress** (self-hosted)
- **Contact Form 7** — contact form functionality
- **Custom CSS/JS** — hand-written styles, scroll-reveal animations, no page builder plugin used
- Google Fonts (Playfair Display, Outfit, JetBrains Mono)

## Development Environment

- Built locally using **LocalWP**
- Deployment to **InfinityFree** free hosting is in progress (files being transferred via FTP due to free-tier upload size limits on the plugin-based migration path)
